# trubo

trubo is a terminal coding assistant written in Go, built on the Anthropic API. It can read, edit and create files in the directory you run it from, and run shell commands there, asking for your approval before every change and command. It was built externally, coded by hand with help from other AI coding tools, until [a62908b](https://github.com/Jack4Code/trubo/commit/a62908bbd3e3bab6bd55076191b40daff38e10a0) gave it the ability to edit files; from [887e259](https://github.com/Jack4Code/trubo/commit/887e2595ac16593fb4533031a8c606e702913a76) on, trubo has written its own features. Project-specific instructions go in a `TRUBO.md` file at the project root. Run it with `ANTHROPIC_API_KEY` set and `go run .`. Future plans include support for other models such as OpenAI and Gemini, MCP support, and a nicer terminal interface.
